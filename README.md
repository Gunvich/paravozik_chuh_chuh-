# 🚂 Paravozik Chuh-Chuh

Короткий опис вашої гри: жанр, основний сеттинг та головна ідея проєкту.

## 🛠 Tech Stack / Технології

* **Engine:** Unity (LTS)

* **IDE:** JetBrains Rider

* **Version Control:** Git / GitHub

* **Code Standard:** C# (.NET)

## 🚀 Quick Start / Як запустити проєкт

1. Клонуйте репозиторій до себе на ПК:

   ```
   git clone https://github.com/Gunvich/paravozik_chuh_chuh-.git
   
   ```

2. Відкрийте **Unity Hub**.

3. Натисніть **Add** $\rightarrow$ **Add project from disk** та виберіть папку з проєктом.

4. Запустіть проєкт через потрібну версію Unity (перша завантажка може зайняти кілька хвилин, поки Unity згенерує кеш).

5. Стартова сцена розташована за шляхом: `Assets/Scenes/Main.unity`

## 🌿 Git Workflow / Структура гілок

* **`main`** — стабільні релізні збірки проєкту.

* **`develop`** — основна гілка для збірки, розробки та тестування.

* **`intro`** — робоча гілка для розробки кат-сцени та вступного інтро.

* **`feature/*`** — персональні гілки під окремі механіки, локації та асети.
